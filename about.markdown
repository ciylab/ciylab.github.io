Le projet est né de la volonté de permettre à tous d'utiliser des modules eurorack bon marché à base d'Arduino permettant de contrôler des signaux MIDI ou des CV/GATE. Le code est ouvert pour l'adapter à des besoins spécifiques.

Pour ceux qui ne sentent pas de fabriquer les modules eux-mêmes, on trouvera quelques exemplaires ici :

[CIYLab.com](https://www.ciylab.com/)
